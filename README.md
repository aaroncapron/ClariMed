# ClariMed 

[![Version](https://img.shields.io/badge/version-0.9.0-blue.svg)](https://github.com/aaroncapron/ClariMed)
[![License](https://img.shields.io/badge/license-TBD-lightgrey.svg)](LICENSE)

## Overview
ClariMed is a medical data processing tool designed to parse, normalize, and organize health and pharmacy workflow data into structured outputs.

## Features
- Standardizes unstructured clinical text and pharmacy parameters into normalized schemas.
- Features API endpoints for integration with data analysis pipelines.
- Supports automated data validation and formatting.

## Tech Stack
- Language: Python
- Frameworks/Libraries: Flask, Pandas, SQLite
- Protocols: RESTful API

## Getting Started
1. Clone the repository:
   git clone https://github.com/aaroncapron/ClariMed.git
2. Install dependencies:
   pip install -r requirements.txt
3. Run the application:
   python app.py
